# Security policy

## Scope

This policy covers:

- the public GitHub repository [codebywout/scouts-Lille-Poederlee](https://github.com/codebywout/scouts-Lille-Poederlee)
- the associated website documented in this project, [scoutslille.be](https://scoutslille.be)

It does not cover third-party services, unrelated forks, or deployments that are not based on this project.

## Reporting a vulnerability

Report security issues **only through a private channel**. A public GitHub issue, pull request, discussion, or any other public mention of a vulnerability is **not** an acceptable way to report.

1. **If private vulnerability reporting is available** for this repository, use that feature (GitHub Security Advisories / private vulnerability reporting):

   https://github.com/codebywout/scouts-Lille-Poederlee/security

2. **Otherwise**, contact the repository owner on GitHub ([@codebywout](https://github.com/codebywout)) privately. Share technical details only after they confirm how to receive them.

Do not include vulnerability details, personal data, secrets, or exploit steps in any public place.

When reporting, include enough information to reproduce the issue (affected URL or component, steps, expected vs actual behaviour). Omit credentials, production data, and unnecessary personal information.

## Public disclosure

Please do not publish vulnerabilities, secrets, or exploitable details until the maintainers have had a reasonable opportunity to assess and address the report. Coordinated disclosure is appreciated; no bug bounty or fixed response timeline is offered.
