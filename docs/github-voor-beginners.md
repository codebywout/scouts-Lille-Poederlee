# Wat is GitHub? (kort)

GitHub is **niet** nodig om teksten, foto’s of brieven te beheren — dat doe je op de **live site** na `/login`.

| | Live website | GitHub |
| --- | --- | --- |
| Wat bezoekers zien | Ja | Nee |
| Wijzigingen via beheer | Meteen op de site | Niet automatisch |
| Foto’s en PDF’s | Op de hosting | Meestal niet hier |
| Volledige inhoudsbackup? | Hangt van jullie backups af | Nee |

Bestanden op GitHub gaan niet vanzelf live; bij codewijzigingen moet iemand de hosting bijwerken. Zet nooit wachtwoorden in GitHub.
