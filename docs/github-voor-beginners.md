# Wat is GitHub? (kort)

Je hebt GitHub **niet** nodig om teksten, foto’s of brieven te beheren.  
Gebruik daarvoor de beheeromgeving: [handleiding-scoutsleiding.md](handleiding-scoutsleiding.md).

## In één zin

**GitHub** is een website waarop de bestanden van dit project bewaard kunnen worden.  
Dat is iets anders dan de live scoutswebsite die bezoekers openen.

| | Live website | GitHub |
| --- | --- | --- |
| Wat bezoekers zien | Ja | Nee |
| Wijzigingen via beheer (“Opslaan”) | Meteen op de site | Niet automatisch |
| Foto’s en PDF’s | Op de hosting | Meestal niet hier |
| Volledige backup van alles? | Hangt van jullie backups af | Nee |

## Wat je wél moet weten

- Inhoud beheer je op de **live website** (na inloggen).  
- Bestanden op GitHub gaan **niet** vanzelf naar de live site. Iemand moet de hosting bijwerken als de programmacode wijzigt.  
- Zet nooit wachtwoorden in GitHub.
