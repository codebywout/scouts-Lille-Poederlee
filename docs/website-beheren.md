# Website-inhoud: waar wijzig je wat?

Eenvoudige regel:

> **Teksten, foto’s, brieven, agenda, leiding** → beheeromgeving.  
> **Uiterlijk, nieuwe pagina’s, menu** → code (technische hulp).

Stap-voor-stap beheer: [handleiding-scoutsleiding.md](handleiding-scoutsleiding.md).

## Beheeromgeving of GitHub?

| Situatie | Doe dit |
| --- | --- |
| Typfout in de FAQ | Beheeromgeving → Home → FAQ → opslaan |
| Nieuwe maandplanning | Beheeromgeving → tak → PDF |
| “Op GitHub staan andere teksten” | Dat kan. De **live website** is leidend voor inhoud. |
| Logo of huisstijl wijzigen | Technische hulp (niet via Foto’s/Achtergronden voor het merkteken in de kop) |

Gebruik voor gewone inhoud altijd de **beheeromgeving**, niet GitHub.

---

## Optioneel: Google Drive

Onder **Instellingen** kan Google Drive gekoppeld worden. Of jullie dat gebruiken, moet de huidige beheerder zeggen. Zonder Drive werkt de rest van de site gewoon.

---

## Als je twijfelt

1. Bestaat er een knop of veld in de beheeromgeving? → Gebruik dat.
2. Anders → [technische-handleiding.md](technische-handleiding.md) of iemand met technische ervaring.
3. Wis nooit “gokkend” bestanden op de hosting.
